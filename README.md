# dounsos · 豆豆店务小程序

基于 uni-app + Vue 3 的微信小程序界面体验版。源码、锁定依赖、测试和构建产物均位于本目录。

**目前使用本机演示数据，未接入 CMP5、真实身份系统或 OSS。可以测试界面、上传体验版供内部验证；不能作为真实门店生产系统发布营业。**

## 立即导入微信开发者工具

1. 打开微信开发者工具，选择「导入项目」。
2. 目录选择 `D:\AI开发项目\店务小程序\豆豆店务小程序`。根目录 `project.config.json` 已指向 `dist/build/mp-weixin/`。
3. 工程已同步您在开发者工具中填写的小程序 AppID；请使用该小程序有开发权限的微信账号登录。若更换小程序，请按下节同步修改 AppID 后构建。
4. 不需要开通微信云开发，本项目当前不依赖云开发。
5. 编译后使用演示账号登录：**store001 / Doudou123**。
6. 如果工具提示找不到 app.json，直接导入 `dist/build/mp-weixin`，不要导入 `src`。

预先构建的目录已经包含 app.json、app.js、app.wxss、WXML、WXSS、页面 JSON 及运行时，不需要在微信开发者工具中再执行「构建 npm」。

## 配置自己的 AppID

在本目录打开 PowerShell：

```powershell
node scripts/set-appid.mjs wx你的16位AppID
npm run build:mp-weixin
```

上面的 AppID 是格式示意，请替换为真实值。脚本会同步更新根目录和 manifest 配置。AppID 不是 AppSecret，本工程不需要在前端配置 AppSecret。

也可手动同时修改 `project.config.json` 的 `appid` 与 `src/manifest.json` 的 `mp-weixin.appid`，然后重新构建。只在工具里修改生成目录配置，可能在下一次构建时被覆盖。

## 功能演示路径

### 订货 → 收货 → 差异

工作台 → 门店订货 → 选择商品 → 保存并核对 → 提交审核 → 在单据底部「演示流程控制」模拟审核通过 → 业务单据 / 收货单 → 输入合格与破损数量 → 确认收货。

存在短收或破损时，必须填写说明，系统生成差异单；从「差异核对」填写核对意见并确认。此动作只是演示记录，不产生真实库存调整。

### 退货

业务单据 → 收货单 → 已收货 → 申请退货 → 输入数量与原因 → 保存草稿 → 提交审核 → 模拟审核通过 → 填写物流或交接信息 → 确认退货出库 → 模拟配送中心接收。

业务单据页提供订货单、收货单、差异单、退货申请单四个独立功能入口。点击后进入各自列表，使用搜索框和状态选择器筛选，不通过横向 tab 切换单据类型。

可退数量会扣除已提交和已完成退货数量；取消或驳回会释放占用。可以从预置的已收货单直接体验。

### 登录与重置

密码不保存；会话持久化并支持模拟令牌刷新。退出清除本地会话及订货输入，已提交演示单据保留。清空微信开发者工具的 Storage 后重新编译，可恢复演示种子数据。

演示数据库存放在设备本地，每台设备相互独立，没有多人协同。演示鉴权、审批和权限检查不代表生产安全能力。

## 本地开发和构建

建议使用受支持的 Node.js LTS；本次验证环境为 Node.js 24。使用 package-lock.json 固定依赖：

```powershell
npm ci
npm test
npm run build:mp-weixin
```

持续开发：`npm run dev:mp-weixin`；输出 `dist/dev/mp-weixin`，开发者工具需导入这个目录。发布构建输出 `dist/build/mp-weixin`，两者不要混用。

H5 只用于辅助界面检查，不作为交付发布平台：`npm run dev:h5`。

## 上传体验版与正式发布

绑定真实 AppID 后，由该小程序的管理员或有权限的开发者在微信开发者工具登录、编译、预览并上传。上传版本号可用 `0.1.0`，描述填写「门店界面及流程体验版，模拟数据」。上传后在微信公众平台管理版本并配置体验人员。

当前可以上传内部体验，不建议提交为实际营业版本。正式发布前必须完成 CMP5 接入、OSS 配置、权限/库存验收及微信平台要求的主体、类目和隐私等检查。`npm run check:release` 仅做静态配置预检查，不代替业务验收，也不执行上传。

工程没有代替您登录微信开发者工具、进行手机真机验证或上传到微信后台。
